先讀取我的檔案結構，完成之後生成一個README檔案，加入到rules當中。
此專案為影像對位 (image registration) 的應用，內容為
3種不同的細胞染色圖Her2、HE、DISH，但是為同一個細胞 這三張圖片的細胞為同一個細胞，
不過經過人工染色之後，會產生偏移、旋轉、平移等等不同的變化，
這些影像本質上是同一個細胞，但因為處理過程中會有
偏移、旋轉、縮放、非線性變形，所以需要合適的演算法來對齊。

你必須嚴格按照該流程來重新設計code以及編譯執行:
工作流程
1. python-轉換
先讀取位於picture/資料夾底下的czi圖檔，並轉換成tiff檔案，存放在picture/tiff資料夾底下
2. C++ 運算
    圖片位於工作流程1的picture/tiff/，且確保都計算都以cuda加速，除非對效能無太大幫助。
    1. 選HE染色影像作為 "基準"。
    2. 先用 特徵點（SIFT/ORB+RANSAC） 粗對齊。
    3. 再用 互信息 + 仿射變換 進一步精準對齊。
    4. 若需要像素級疊合（細胞邊界完全重疊），最後用 B-spline FFD 做非剛體對齊。
    5. 使用評估指標評估是否3張圖片疊合正確，分成good/normal/bad
        - 互資訊 (MI) 
        - 正規化互資訊 (NMI)
        - 目標配準誤差 (TRE)
    6. 把經過演算法處理的圖片，共四張，Her2、HE、Dish、3張圖片的疊合圖，存放到picture/output/中
3. python-PyQt5 Gui
    1. 讀取 C++ 運算處理完成的圖片，位於 picture/output/ 目錄底下。
    2. 建立一個 GUI 介面，分為三個主要區域：
        - 左側：檔案清單，顯示 picture/output/ 底下的圖片檔案 (Her2, HE, Dish, 疊合圖)。
        - 中央：影像顯示區，能夠切換並顯示使用者點選的圖片。
        - 右側：結果資訊面板，顯示 C++ 運算輸出的評估指標 (MI、NMI、TRE) 與對應的等級 (good/normal/bad)。
    3. GUI 功能需求：
        - 支援基本的影像操作：縮放、平移、旋轉。
        - 提供一個「比較模式」按鈕，可以把兩張圖（例如 HE 與 Her2）疊合後半透明顯示，供人工檢視對位效果。
        - 提供「三圖合成模式」按鈕，顯示 Her2、HE、Dish 疊合後的最終結果。
        - 提供「重新整理」按鈕，允許在 C++ 運算完成後不需重啟程式即可更新結果。
    4. 程式結構：
        - `main.py`：GUI 主程式入口。
        - `viewer.py`：影像顯示控制，負責縮放/平移/旋轉。
        - `metrics.py`：讀取並解析 C++ 運算產生的評估結果檔案 (json/txt 格式)。
        - `ui/`：存放 Qt Designer `.ui` 檔案，方便維護 UI 佈局。
    5. 介面設計原則：
        - 以 PyQt5 為基礎，不依賴外部不必要套件。
        - 保持簡潔清晰，研究人員可快速查看結果，不需過多互動操作。
        - 所有圖片顯示皆維持原始大小比例，不進行二次處理。

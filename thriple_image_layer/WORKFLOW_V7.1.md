# 醫療影像對齊系統 - 模組化離線處理與定量分析工作流程 (V7.1)

**版本**: 7.1  
**更新日期**: 2025-10-12  
**核心思想**:  
以模組化思維重構整個醫療影像分析流程。系統分為三大模組：  
1️⃣ 一次性離線預處理、  
2️⃣ 快速離線對準、  
3️⃣ 計算密集型定量分析。  
三者構成從原始 `.czi` 影像到最終 `.csv` 報告的端到端自動化流程。

## 模組化流程說明

### **Module 1: Preprocessing Pipeline (一次性離線處理)**

**目的**：  
準備原始 `.czi` 影像作為 VALIS 可直接讀取的輸入，並進行必要的影像優化（如亮度正規化、去噪、遮罩生成等），讓後續對準步驟能穩定運作。

**輸入**：  
原始 `.czi` 全玻片影像 (可能包含多通道、多層級)

**處理內容 / 方法**：  
- 使用 **VALIS 的 Slide I/O／讀取器模組** 直接讀取 `.czi` 檔案，透過其內建支援（Bio‑Formats、OpenSlide、libvips）自動載入多層影像。  
- 於讀取後進行影像正規化（Normalization）、遮罩生成 (tissue mask) 與顏色校正。  
- **不再需要額外產生 OME‑TIFF 金字塔結構**，除非為後續視覺化或儲存之需。  

**輸出**：  
- 經過優化、正規化與遮罩處理的影像資料（作為 VALIS 對準模組的直接輸入）  
- （可選）VALIS 可將對齊結果輸出為 OME‑TIFF（視需求啟用）  

---

### **Module 2: Alignment Pipeline (快速離線對準)**

**目的**:  
以「VALIS式群組對準」為核心，對多組影像進行全域與局部階層式配準，生成可重複應用的變換參數。

**輸入**:  
- 經優化的影像資料 (`.czi` / 中階影像)
- 遮罩檔案 (`.png`)

**方法與工具**:
- **VALIS + OpenCV**：特徵匹配與群組式註冊  
- **SimpleElastix**：非剛性配準精化  
- 支援金字塔層級與批次配準

**輸出**:  
- `Transform_Params.h5` (包含全域與區塊層級的變換矩陣)

---

### **Module 3: Quantitative Analysis Pipeline (計算密集型分析)**

**目的**:  
利用前兩階段對齊後的影像，進行細胞分割、特徵量化與結果統計，最終輸出分析報告。

**輸入**:  
- 對齊後的影像資料  
- 對應的變換參數 `.h5`

**方法與工具**:
- **Cellpose / StarDist**：細胞實例分割  
- **scikit-image**：形態學特徵提取  
- **Pandas**：特徵彙整與統計輸出  

**輸出**:  
- `Analysis_Report.csv` (包含細胞數量、核面積、染色強度等統計項目)

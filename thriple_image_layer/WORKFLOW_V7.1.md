### **系統架構與數據流 ASCII 圖**

```
+----------------+     +----------------+     +----------------+
| Dish.czi       |     | HE.czi         |     | Her2.czi       |  <-- 原始高解析度檔案
+----------------+     +----------------+     +----------------+
        |                      |                      |
        ▼                      ▼                      ▼
+-------------------------------------------------------------+
|    Module 1: Preprocessing (在低解析度下進行)               |
|  - 讀取影像金字塔頂層 (e.g., ~1000px, <5MB)                  |
|  - 影像正規化 (讓 HE/Dish/Her2 看起來相似)                   |
|  - 生成組織遮罩                                             |
+-------------------------------------------------------------+
        | (產生三個低解析度影像 + 遮罩)
        ▼
+-------------------------------------------------------------+
|    Module 2: Alignment (在低解析度下計算)                   |
|  - 特徵匹配 -> 自動排序 (HE 可能會被置於中間)               |
|  - 序列剛性對準 (Serial Rigid)                              |
|  - 高解析度裁剪區非剛性對準 (Non-rigid on cropped area)     |
+-------------------------------------------------------------+
        | (僅輸出一個小型檔案)
        ▼
+-------------------------------------------------------------+
|    Transform_Params.h5 (~MBs)                               |  <-- 核心產出：變換參數
+-------------------------------------------------------------+
        |
        ▼
+-------------------------------------------------------------+
|    Module 3: Quantitative Analysis (高效應用)               |
|  - 1. 在原始 *.czi 上進行細胞分割 (Cellpose)                |
|  - 2. 提取細胞座標 (Centroids)                              |
|  - 3. 將座標應用 Transform.h5 進行變換 (Warp Coords)        |
|  - 4. 使用對齊後的座標進行統計分析 (Pandas)                 |
+-------------------------------------------------------------+
        |
        ▼
+-------------------------------------------------------------+
|    Analysis_Report.csv                                      |  <-- 最終產出：分析報告
+-------------------------------------------------------------+
```

### **模組化流程設計 (Context for AI Code Generation)**

以下是每個模組的詳細設計，您可以將此 Markdown 表格內容直接貼給 AI 程式碼助理，它將能理解整個任務的上下文、目標、使用的函式庫及關鍵參數。

#### **Module 1: Preprocessing Pipeline**

**目標**: 將三個 6.5GB 的 CZI 檔案轉換為適合對準的小型、標準化影像。

| 步驟 | 動作/目標 | 關鍵參數 & 函式庫/方法 (給 AI 的提示) | 效率與記憶體考量 |
| :--- | :--- | :--- | :--- |
| 1.1 | **讀取影像** | **`valis.SlideReader`**<br>- `imgs_path`: `['Dish.czi', 'HE.czi', 'Her2.czi']`<br>- `series`: `0` (因 S 維度=1)<br>- `level`: 選擇一個讓影像最大維度在 `850`\~`1500` 像素之間的金字塔層級。**不要用 level=0！** | **這是最重要的步驟**。不讀取 6.5GB 的 level 0，而是讀取金字塔上層的小影像，記憶體佔用從 GB 降至 MB 等級。 |
| 1.2 | **影像正規化** | 使用 VALIS **預設的預處理器** (`valis.preprocessing.DefaultValisPreprocessor`)。<br>它會自動處理不同染色的影像，將其轉換為適合特徵匹配的灰階影像。 | 在小型影像上操作，計算成本極低。H\&E 染色通常結構最豐富，會是特徵匹配的良好基礎。 |
| 1.3 | **生成遮罩** | **`valis.mask.get_tissue_mask`**<br>- 使用預設參數即可。 | 同樣在小型影像上操作，快速且節省記憶體。遮罩能讓後續步驟只專注於組織區域，提升效率和準確性。 |

#### **Module 2: Alignment Pipeline**

**目標**: 使用低解析度影像計算出精確的變換參數，並儲存為 `.h5` 檔案。

| 步驟 | 動作/目標 | 關鍵參數 & 函式庫/方法 (給 AI 的提示) | 效率與記憶體考量 |
| :--- | :--- | :--- | :--- |
| 2.1 | **初始化對準器** | **`valis.Valis`**<br>- `src_f` (來源檔案路徑)<br>- `results_dst` (結果儲存目錄)<br>- `reference_img_f`: **不要設定**，讓 VALIS 自動排序。 | 初始化只設定路徑，不佔用大量記憶體。 |
| 2.2 | **執行對準** | **`registrar.register()`**<br>- `micro_register`: `False` (為了效率，先關閉微對準)<br>- `align_to_reference`: `False` (使用群組式對準) | 整個計算密集型過程都在低解析度影像上進行。VALIS 會自動排序，將最相似的影像（如 HE 和 Her2）放在一起，提高成功率。 |
| 2.3 | **儲存變換參數** | `registrar.register()` 會自動儲存 `Transform_Params.h5` 檔案。 | 輸出的 `.h5` 檔案非常小，僅包含數學變換矩陣和位移場，易於儲存和傳遞。 |

#### **Module 3: Quantitative Analysis Pipeline**

**目標**: 不對 6.5GB 影像做扭曲，而是直接扭曲細胞座標，高效完成定量分析。

| 步驟 | 動作/目標 | 關鍵參數 & 函式庫/方法 (給 AI 的提示) | 效率與記憶體考量 |
| :--- | :--- | :--- | :--- |
| 3.1 | **(可選) 載入變換** | **`valis.load_valis(h5_path)`**<br>- 讀取 Module 2 產生的 `.h5` 檔案。 | 載入的 `registrar` 物件包含了所有變換資訊，記憶體佔用小。 |
| 3.2 | **細胞分割** | **`Cellpose` / `StarDist`**<br>- 遍歷三張**原始** `.czi` 檔案，可使用 `pyvips` 或 `openslide-python` **逐塊 (tile by tile)** 讀取，避免一次載入 6.5GB。 | **這是記憶體優化的關鍵**。透過 Tiling 方式處理大圖，每次只將一小塊影像送入模型進行分割，記憶體可控。 |
| 3.3 | **提取與變換座標** | 1. 從分割結果中提取每個細胞的中心點 (x, y) 座標，存入 `pandas.DataFrame`。<br>2. 使用 **`registrar.warp_xy(xy_array, slide_src_f, ...)`** 將每個檔案的座標變換到對齊後的空間。 | **這是效率的關鍵**。變換數千或數萬個座標點的計算成本遠低於變換數十億像素的影像。整個過程在幾秒或幾分鐘內完成。 |
| 3.4 | **統計分析** | **`pandas`, `scikit-image`**<br>- 在**對齊後的座標**上進行空間統計分析（如細胞密度、最近鄰距離等）。<br>- 從原始影像的對應座標提取染色強度等特徵。 | 所有分析都在結構化的 `DataFrame` 上進行，高效且靈活。 |

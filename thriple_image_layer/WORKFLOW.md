## 參數轉換流程

```
┌──────────────────────────────────────────────────────────────┐
│                    參數空間轉換鏈                              │
└──────────────────────────────────────────────────────────────┘

    PNG 空間                CZI 完整空間              CZI 縮放空間
    ────────                ────────────              ────────────

Her2_mask.png          P2525729F_HER2.czi         HER2 (0.2x)
31877 x 24444    ───►  159388 x 122224      ───►  31877 x 24444
                  ×5.0                        ×0.2

    │                        │                        │
    │ H_png                  │ H_czi_full             │ H_czi_scaled
    ▼                        ▼                        ▼

DISH_mask.png          P2525729F_DISH.czi         DISH (0.2x)
40314 x 30544    ───►  161259 x 122176      ───►  32252 x 24435
                  ×4.0                        ×0.2


變換矩陣關係:

H_czi_full = S_ref × H_png × S_mov⁻¹

其中:
┌           ┐       ┌           ┐
│ 4.0  0  0 │       │ 0.2  0  0 │
│ 0  4.0  0 │       │ 0  0.2  0 │
│ 0    0  1 │       │ 0    0  1 │
└           ┘       └           ┘
   S_ref              S_mov⁻¹


H_czi_scaled = S × H_czi_full × S⁻¹

其中:
┌           ┐
│ 0.2  0  0 │
│ 0  0.2  0 │
│ 0    0  1 │
└           ┘
      S
```

## 品質控制檢查點

```
✓ Checkpoint 1: PNG 配準完成
  ├─ RANSAC 內點 > 100
  ├─ SSIM > 0.7
  ├─ 視覺檢查: registration_visualization.png
  └─ ✓ 通過 → 繼續 CZI 驗證
     ✗ 失敗 → 調整配準參數重試

✓ Checkpoint 2: CZI 驗證完成  
  ├─ SSIM > 0.6 (縮放影像標準較寬鬆)
  ├─ 重疊區域 > 80%
  ├─ 視覺檢查: czi_validation_results.png
  │  ├─ 棋盤格對齊良好
  │  ├─ 邊緣對齊準確
  │  └─ 局部放大無明顯錯位
  └─ ✓ 通過 → 參數可用於生產
     ✗ 失敗 → 檢查 CZI 載入或返回 PNG 配準
```

## 使用場景建議

### 場景 1: 快速驗證（開發階段）
```
1. image_registration_pipeline.py  (SIFT)
2. visualize_results.py
→ 檢查 PNG 結果即可
⏱ 總時間: ~1 分鐘
```

### 場景 2: 標準驗證（推薦）
```
1. image_registration_pipeline.py  (SIFT)
2. validate_czi_registration.py    (0.2x)
→ PNG + CZI 完整驗證
⏱ 總時間: ~5 分鐘
```

### 場景 3: 高精度驗證（最終確認）
```
1. image_registration_pipeline.py  (SIFT)
2. validate_czi_registration.py    (0.5x)
→ 更高解析度 CZI 驗證
⏱ 總時間: ~15 分鐘
💾 需要: 40+ GB RAM
```

### 場景 4: 批次處理
```
1. 修改 main() 函數添加迴圈
2. 對多組影像執行 PNG 配準
3. 統一執行 CZI 驗證
→ 適用於多個樣本
```

# 醫療影像對齊系統 - 整合式雙前處理與混合對齊工作流程 (V6.0)

**版本**: 6.0  
**更新日期**: 2025-10-08  
**核心思想**: 一個完整的端到端 (End-to-End) 流程。首先將 DISH 與 Her2 兩種 WSI 轉換為灰階影像並增強對比度；然後，利用這兩份灰階影像，執行從全域到局部的混合式階層對齊策略。

## 各階段詳細流程

### Phase 0: 影像前處理 - 灰階轉換

此階段將彩色 WSI 轉換為灰階影像，簡化後續對齊計算。

#### 0.1: DISH 影像前處理 (`preprocess_dish_image.py`)

1.  **讀取影像**:
      * **輸入**: `DISH.tiff` 的指定層級 (預設 Level 1)。
2.  **灰階轉換**:
      * **方法**: 使用 OpenCV 的 `cvtColor(RGB2GRAY)` 將 RGB 影像轉換為灰階。
3.  **對比度增強**:
      * **方法**: 應用自適應 CLAHE 增強組織結構對比度。
      * **輸出**: `DISH_Gray.tiff` (單通道灰階影像)。

#### 0.2: Her2 影像前處理 (`preprocess_her2_image.py`)

1.  **讀取影像**:
      * **輸入**: `Her2.tiff` 的指定層級 (預設 Level 1)。
2.  **灰階轉換**:
      * **方法**: 使用 OpenCV 的 `cvtColor(RGB2GRAY)` 將 RGB 影像轉換為灰階。
3.  **對比度增強**:
      * **方法**: 應用自適應 CLAHE 增強組織結構對比度。
      * **輸出**: `Her2_Gray.tiff` (單通道灰階影像)。

### Phase 1: 全域階層式對齊 (`global_hierarchical_aligner.py`)

此階段利用 Phase 0 產出的純淨輪廓影像，進行高效且穩健的全域對齊。

1.  **輸入**:
      * **參考影像 (Reference)**: `DISH_Gray.tiff`。
      * **浮動影像 (Moving)**: `Her2_Gray.tiff`。
2.  **對齊過程**:
      * 由於兩張輸入影像均為清晰的灰階結構圖，可以直接使用 SIFT/ORB 等標準特徵檢測器來尋找地標點。
      * 從最低解析度層級開始計算初始變換矩陣 `H_global_coarse`。
      * 將變換矩陣逐層向上傳播並優化，直至最高解析度，得到 `H_global_final`。

### Phase 2: 局部區塊精細化 (`local_patch_refiner.py`)

此階段利用 Phase 1 的全域對齊結果作為基礎，對影像進行分區處理，以校正微小的局部非剛性形變。

1.  **影像分區**: 將 `DISH_Gray.tiff` 劃分為網格。
2.  **獨立區塊對齊**: 對每一對區塊（DISH 輪廓區塊 vs Her2 輪廓區塊）執行獨立的精細對齊，得到一組局部優化變換。此過程可高度平行化。
3.  **拼接與融合**: 將所有局部對齊後的 Her2 區塊拼接融合，得到最終的 `Her2_fully_aligned.tiff`。(注意：此處的變換是應用於原始的 `Her2.tiff` 彩色影像上)。

### Phase 3: 視覺化驗證 (`visualize_final_overlay.py`)

此階段是最終的品質控制與成果交付。

1.  **生成疊合影像**: 將**原始的 `DISH.tiff`** 和經過完整變換後**彩色的 `Her2_fully_aligned.tiff`** 疊合成一張高品質影像 `DISH_Her2_Overlay_Final.png`，用於直觀地檢查對齊效果。
2.  **量化評估**: 計算最終對齊灰階影像 (`DISH_Gray.tiff` vs `Her2_Gray_aligned.tiff`) 的品質指標（SSIM, NCC, MI）以進行量化評估。

## 個名詞解釋
1. 經過完整變換後彩色的 Her2_fully_aligned.tiff
### 核心概念：我們在「灰階輪廓」上計算變換，但將變換應用於「原始彩色」影像

整個 V6.0 工作流程可以分為兩個主要部分：

1.  **計算對齊參數 (Calculation Phase)**:
    * 我們在 **Phase 0** 中，將彩色的 `DISH.tiff` 和 `Her2.tiff` 轉換為**灰階影像** (`DISH_Gray.tiff` 和 `Her2_Gray.tiff`)。
    * 我們在 **Phase 1** 和 **Phase 2** 中，**完全使用這兩張灰階影像**來進行所有的對齊計算。從全域的 `H_global_final` 到每個小區塊的局部變換 `H_local_i`，所有的數學運算都是基於這些輪廓圖完成的。
    * **為什麼這麼做？** 因為灰階影像去除了顏色干擾，保留組織結構資訊，簡化對齊計算。

2.  **應用變換參數 (Application Phase)**:
    * 當我們完成了所有的計算，手上就有了一套完整的「變換指令集」（包含全域和所有局部變換）。這套指令集精確地描述了 `Her2.tiff` 中的每一個像素點，應該移動到哪個新的位置，才能與 `DISH.tiff` 完美對齊。
    * 現在，我們回到**最原始的、全彩色的 `Her2.tiff` 影像**。
    * 我們將剛剛計算出的那套完整的「變換指令集」，**應用 (Apply)** 在這張原始的彩色影像上。
    * 這個應用的過程會生成一張全新的影像。這張新影像就是 **`Her2_fully_aligned.tiff`**。

### 「經過完整變換後彩色的 Her2_fully_aligned.tiff」的具體含義

* **彩色的 (Color)**: 這張影像保留了 `Her2.tiff` 所有的原始色彩信息，包括蘇木精的藍色和 DAB 的棕色。我們沒有丟失任何視覺信息。
* **經過完整變換後 (Fully Transformed/Aligned)**: 這張影像的幾何形態已經被徹底重塑。它不再是原始 `Her2.tiff` 的樣子，而是經過了 Phase 1 (全域校正) 和 Phase 2 (局部精細校正) 兩輪完整的空間變換。它的每一個像素都已經被精確地移動到了與 `DISH.tiff` 對應的空間位置上。
* **.tiff**: 它被儲存為 TIFF 格式，以保留完整的影像品質。

**簡單比喻：**

想像一下，您有兩張部分重疊的透明地圖（`DISH` 和 `Her2`），但其中一張（`Her2`）被稍微旋轉和拉伸了。

1.  您先拿出兩張地圖的**描圖紙副本**（灰階的 `_Hematoxylin.tiff`），在描圖紙上比對海岸線（細胞核輪廓），計算出需要將 `Her2` 旋轉多少度、拉伸多少才能對齊。
2.  計算完成後，您**扔掉描圖紙**。
3.  您回到**原始的、彩色的 `Her2` 透明地圖**，按照剛剛在描圖紙上計算出的精確角度和拉伸量，對它進行物理變換。
4.  變換完成後的這張彩色地圖，就是「經過完整變換後彩色的 `Her2_fully_aligned.tiff`」。

H_global_coarse
### 核心概念：`H_global_coarse` 的意義與角色
`H_global_coarse` 是我用來描述**在階層式對齊的第一步所計算出來的「初始全域變換矩陣」**。

* **H**: 在圖像處理和電腦視覺領域，`H` 是 **Homography Matrix (單應性矩陣)** 的標準縮寫。簡單來說，它是一個 3x3 的矩陣，可以用來描述一張影像如何透過旋轉、縮放、平移、傾斜等二維變換，以對齊到另一張影像上。在我們的案例中，它代表了如何將 `Her2.tiff` 變換以對齊 `DISH.tiff`。

* **global (全域的)**: 這個詞表示該變換矩陣是應用於**整張影像**的，而不是僅僅應用於某個局部小區域。它的目標是校正兩張圖整體的錯位。

* **coarse (粗略的)**: 這個詞是整個概念的關鍵。它表示這個變換矩陣是在**最低解析度的影像（Level 4）**上計算出來的。因為使用的是縮圖，損失了很多細節，所以這個對齊結果是**粗略的、不夠精確的**。

**所以，`H_global_coarse` 的完整意思是：**

> 一個在低解析度影像上快速計算出來的、用於描述兩張完整影像之間大致對齊關係的變換矩陣。

**它在 Workflow 中的角色是什麼？**

在工作流程的 **Phase 1** 中，我們不是直接在數十億像素的原圖上進行運算（這會非常慢且消耗記憶體），而是效法論文的精神，從最小的 Level 4 影像開始。

1.  我們在 Level 4 影像上，透過顏色解卷積等方法，找到對應特徵點。
2.  基於這些點，我們計算出 `H_global_coarse`。這個過程非常快。
3.  然後，我們把這個「粗略」的結果作為一個非常好的**初始猜測**，逐層向上傳播到 Level 3, Level 2... 在每一層都對它進行微調和優化。
4.  最終在最高解析度的 Level 0 得到的，就是 `H_global_final` (最終的全域變換矩陣)。

簡單來說，`H_global_coarse` 就是整個階層式對齊過程的**起點**和**基礎**，沒有它，就無法高效地進行後續的精細化對齊。

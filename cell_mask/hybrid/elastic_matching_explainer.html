Elastic DISH Nucleus Matching

解決 IHC 與 DISH 兩張切片因物理飄移無法直接像素對齊的問題。
以三步驟在不做影像配準的情況下，完成細胞核彈性分配。

⚠️
問題背景：IHC 染色（Cellpose 分割出 instance_mask）與 DISH 染色（nucleus_mask）是同一組織但獨立製作的切片。 物理上的組織飄移導致同一顆細胞核在兩張影像上的位置不會完全重疊， 因此無法直接用 pixel overlap 判斷「IHC 細胞 ↔ DISH 核」的對應關係。
解法：以面積驅動的等向膨脹作為容忍圈 + centroid greedy 排距分配。
1
Step 1

等向膨脹 Isotropic Dilation

對每一顆 IHC 細胞 region，計算使面積放大至 f 倍所需的 dilation radius r。 膨脹後的 region 作為「容忍圈」，涵蓋 DISH 核可能因飄移落入的範圍。

預設 f = 1.5（面積擴大 50%），對應約 15–20 px 的飄移容忍。

r = (√(A · f) − √A) / √π A = IHC 細胞面積 (pixels) f = dish_elastic_expand_factor （預設 1.5）
2
Step 2

候選收集 Candidate Collection

以 Step 1 的膨脹 region 為範圍，找出所有與其有 像素重疊的 DISH 細胞核， 收集為 candidate list。

不在容忍圈內的 DISH 核直接排除，不進入後續分配，大幅降低比對複雜度。

candidates = [ d_id for d_id in dish_ids if np.any( dilated_region & (dish_mask == d_id) ) ]
3
Step 3

Greedy 距離分配 Greedy Centroid Assignment

對所有 (IHC, DISH) candidate pair，按 centroid 歐氏距離由近到遠排序，依序 greedy 認領：

• 每顆 DISH 核最多被一顆 IHC 認領（exclusive）
• 一顆 IHC 可認領多顆 DISH（多核細胞）
• 距離 > max_dist_px（預設 50 px）直接拒絕

pairs.sort(key=lambda p: p.dist) for (ihc, dish, dist) in pairs: if dist > max_dist_px: break if dish in assigned: continue # 已被搶走 result[ihc].append(dish) assigned.add(dish) # 一顆 IHC → 多顆 DISH OK（多核） # 一顆 DISH → 只屬一顆 IHC

相關 Config 參數 & 回傳值

dish_elastic_expand_factor
預設 1.5
Step 1 膨脹倍數。1.5 = 面積擴大 50%，容忍約 15–20 px 的飄移。
dish_elastic_max_dist_px
預設 50 px
Step 3 centroid 距離上限。超過此距離的 (IHC, DISH) pair 直接拒絕，不分配。
回傳值： { ihc_cell_id: [assigned_dish_id, ...] }
一顆 IHC 可對應多顆 DISH（多核細胞）；一顆 DISH 只屬於一顆 IHC（exclusive）。
未被任何 IHC 認領的 DISH 核 → 不出現在結果中，視覺化上顯示為白色輪廓。
被認領的 DISH 核 → 視覺化上顯示為深粉色輪廓，並畫飄移箭頭。

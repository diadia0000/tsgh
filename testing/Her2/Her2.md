# HER2 棕色細胞膜染色提取 GUI Workflow

1. 讀取圖像  
   - 支援常見格式（.png/.tif/.svs）

2. 色彩分離  
   - RGB → HED（skimage.color.rgb2hed）  
   - 取 DAB 通道（棕色）與 Hematoxylin 通道（藍色核）

3. DAB 通道前處理  
   - 取負號並正規化到 [0,1]  
   - 高斯模糊去噪

4. 二值化與膜區域遮罩  
   - Otsu 或滑桿自訂閾值 T  
   - 形態學處理（開運算、閉運算）  
   - 邊緣檢測（用以強化膜結構）

5. 核區遮罩（對比參考）  
   - Hematoxylin 通道二值化分割細胞核  
   - 作為 ROI 過濾，保留膜在細胞核周圍之區域

6. 膜染色強度分析  
   - 計算膜內 DAB 強度分佈（平均值、百分位）  
   - 標記強度區間（負、1+、2+、3+）

7. 可視化顯示  
   - 原圖 + 膜遮罩疊加（選色：紅或綠半透明）  
   - 強度分區色碼圖例

8. 參數調整介面  
   - 滑桿：DAB 閾值、結構元素大小、模糊半徑  
   - 即時預覽區

9. 結果匯出  
   - 儲存疊加圖（.png）  
   - 匯出量化報告（.csv）：細胞總數、各級別比例

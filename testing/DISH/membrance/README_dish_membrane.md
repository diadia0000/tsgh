# DISH 染色細胞膜遮罩工具

## 概述

本工具用於 DISH (Dual In Situ Hybridization) 染色影像的細胞膜分離和遮罩處理。與細胞核分離不同，此工具專注於識別和提取細胞膜結構，適用於三重染色圖片疊合工作流程。

## 主要特色

- **細胞膜特異性分離**: 採用 LAB 顏色空間和 DAB 通道分析來精確識別 DISH 染色的細胞膜
- **多通道處理**: 結合 LAB、DAB 和 HSV 通道進行綜合分析
- **即時參數調整**: 提供直觀的 GUI 界面，支援即時預覽和參數微調
- **PNG 輸出格式**: 所有結果均以 PNG 格式儲存，便於後續處理
- **統計分析**: 提供詳細的覆蓋率和染色強度統計

## 與細胞核版本的差異

| 特徵         | 細胞核版本 (cell)        | 細胞膜版本 (membrance)        |
| ------------ | ------------------------ | ----------------------------- |
| 主要分析方法 | HSV 顏色閾值 + Watershed | LAB + DAB + HSV 綜合分析      |
| 輸出格式     | TIFF                     | PNG                           |
| 分離目標     | 細胞核                   | 細胞膜                        |
| 顏色空間     | 主要 HSV                 | LAB + DAB (主要) + HSV (輔助) |
| 適用場景     | 細胞計數                 | 三重染色疊合                  |

## 快速開始

### 執行 GUI 工具

```bash
cd testing/DISH/membrance
python dish_membrane_gui.py
```

### 預設參數

- **LAB A 通道**: 115-140
- **LAB B 通道**: 115-145  
- **DAB 範圍**: 10-255
- **Kernel 大小**: 3
- **最小膜面積**: 50 像素

## 參數調整指南

### LAB 顏色閾值 (主要控制)

- **A 通道**: 控制綠-紅色軸，DISH 染色通常在 115-140 範圍
- **B 通道**: 控制藍-黃色軸，調整範圍 115-145
- 這兩個參數是最重要的，直接影響細胞膜識別效果

### DAB 染色強度

- **DAB 最小值**: 過濾弱染色背景，建議 10-30
- **DAB 最大值**: 通常保持 255，除非需要排除過強染色

### HSV 輔助閾值 (可選)

- 預設為全範圍 (H:0-179, S:0-255, V:0-255)
- 可用於進一步精細化篩選特定顏色範圍

### 形態學處理

- **Kernel 大小**: 3-7，影響形態學運算的範圍
- **開運算**: 去除小雜訊，建議 1-2 次
- **閉運算**: 填補小孔洞，建議 1-2 次  
- **膨脹**: 稍微擴大膜結構，建議 0-2 次
- **最小面積**: 過濾過小的膜片段，建議 30-100

## 品質評估標準

### 良好結果指標

- **細胞膜覆蓋率**: 1-30% (視組織密度而定)
- **DAB 平均強度**: >20 (表示染色良好)
- **遮罩連續性**: 膜結構應呈現連續的輪廓
- **雜訊水平**: 背景乾淨，假陽性少

### 常見問題解決

1. **覆蓋率過低** (<1%)
   - 降低 LAB A/B 下限
   - 降低 DAB 最小值
   - 檢查原始影像染色品質

2. **覆蓋率過高** (>30%)
   - 提高 LAB A/B 下限
   - 提高 DAB 最小值  
   - 增加最小面積閾值

3. **膜結構破碎**
   - 增加閉運算次數
   - 適度增加膨脹次數
   - 降低最小面積閾值

4. **背景雜訊多**
   - 增加開運算次數
   - 提高最小面積閾值
   - 調整 HSV 輔助範圍

## 工作流程整合

此工具產生的細胞膜遮罩可直接用於：

1. **三重染色疊合**: 與 HE 和 Her2 的細胞膜遮罩進行配準疊合
2. **共定位分析**: 分析不同染色間的空間關係
3. **定量分析**: 計算膜面積、強度分佈等參數

## 技術說明

### 演算法流程

1. **顏色空間轉換**: RGB → LAB, H&E 解混 → DAB
2. **多通道閾值**: LAB A/B 範圍 + DAB 強度篩選
3. **通道結合**: 邏輯 AND 運算結合多通道遮罩
4. **形態學清理**: 開運算 + 閉運算 + 膨脹
5. **面積過濾**: 移除過小的連通區域
